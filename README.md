# Al Muttaqin Kids V2.5 — Petualangan Kampung Al-Muttaqin (Seri Game #2 Revisi Final)

Versi penyempurnaan menyeluruh untuk repositori **Game-al-muttaqin-kids-V2** resmi milik **Majelis Ta'lim Al Muttaqin** (*zero-build*, siap upload ulang langsung ke **GitHub Pages** tanpa menghapus progres lama pemain).

## Daftar Perbaikan Utama V2.5
1. **Anti-Exploit & Sinkronisasi Studio Hijaiyah**: Menutup celah klik ganda jawaban benar di Mini-Kuis Hijaiyah (`quizLocked`), menyinkronkan pilihan jawaban otomatis saat harakat diubah di tengah kuis, menyempurnakan rasm Alif berharakat (`أَ / إِ / أُ`), dan menambah bonus 5 benar beruntun (`+8 Biji`).
2. **Mode 1 Jejak Kebaikan Lebih Responsif**: Kartu sortir mendukung **drag mouse + sentuh jari (Unified Pointer Events)** dengan animasi miring kiri/kanan, tombol **Jeda (`P`)**, tanda centang (`✓`) langsung diperbarui saat level tuntas, serta **10 ilustrasi properti 3D HD baru** agar kartu tidak monoton.
3. **Ujian Bintang MUMTAZ Acak & Adil**: Urutan 10 soal & opsi jawaban A/B/C/D diacak tiap sesi, Rapor Digital menampilkan **Tanggal Evaluasi otomatis** + tombol **Ganti Nama Santri**, serta sistem hadiah adil anti-spam.
4. **Tipografi Arab Tajam & Audio Lafal**: Beralih ke **Noto Naskh Arabic** (`unicode-bidi: isolate`) + tombol **Dengar Lafal Arab** di seluruh 12 modul 6 Klaster Kurikulum.
5. **UX Ramah Anak, Musik BGM & Offline PWA**: Menghapus `alert()` browser kaku di modal upgrade lokasi (diganti peringatan inline + tombol pintas panen Biji), menampilkan nama singkat lokasi pada pin peta di HP, menambah **Musik Kalimba BGM lembut**, tombol **Layar Penuh**, **Offline PWA (`sw.js`)**, dan tautan navigasi ke **Serial 3 Game Al Muttaqin**.
