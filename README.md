## Cara Update di GitHub (`al-muttaqin-kids`)
1. Ekstrak seluruh isi `al-muttaqin-kids-web-github-v3.zip`.
2. Buka repositori `al-muttaqin-kids` → **Add file → Upload files**.
3. Seret seluruh isi hasil ekstrak (`index.html`, `README.md`, folder `assets`, folder `buku`, dan folder `bab`) → klik **Commit changes**.
4. Tunggu 1–2 menit lalu tekan `Ctrl + Shift + R` di URL GitHub Pages Anda.
