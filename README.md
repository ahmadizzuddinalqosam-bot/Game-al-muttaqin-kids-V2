# Portal Web Al Muttaqin Kids — Majelis Ta'lim Al Muttaqin

Portal Edukasi Islam Anak — **Semesta Kisah Kampung Al-Muttaqin** di bawah naungan **Majelis Ta'lim Al Muttaqin** (*Biro Publikasi & Kurikulum Media Pembelajaran — Majelis Al-Muttaqin Press*).

## Cara Deploy ke GitHub Pages (3 Langkah)
1. Ekstrak seluruh isi ZIP ini (`index.html` dan folder `assets/`) ke root repositori GitHub Anda (misalnya `al-muttaqin-kids`).
2. Buka tab **Settings → Pages** di repositori GitHub Anda.
3. Pada **Source**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
