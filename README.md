## Cara Update ke GitHub (`al-muttaqin-kids`)
1. Ekstrak `al-muttaqin-kids-web-github-v4.zip`.
2. Di repositori GitHub `al-muttaqin-kids` → **Add file → Upload files** → seret seluruh isi hasil ekstrak (`index.html`, `README.md`, `assets`, `buku`, `bab`) → **Commit changes**.
3. Tunggu 1–2 menit lalu tekan `Ctrl + Shift + R` di `https://ahmadizzuddinalqosam-bot.github.io/al-muttaqin-kids/`.
